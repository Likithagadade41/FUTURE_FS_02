# LeadFlow CRM 📊

LeadFlow CRM is a simple and user-friendly **Client Lead Management System** designed to help manage leads, track their progress, add notes, and monitor follow-ups from a centralized dashboard.

## Live Demo

[View LeadFlow CRM Live Demo](YOUR_WORKING_LEADFLOW_DEMO_LINK)

## Features

* Add and manage client leads
* Track lead status: New, Contacted, and Converted
* Add notes and follow-up details
* Dashboard with lead analytics
* Calendar for follow-up management
* Clean and responsive user interface
* Organized client lead management

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Node.js
* Express.js
* MongoDB
* Mongoose

## Project Overview

Developed as part of the **Future Interns Full Stack Web Development Internship – Task 2**, this project focuses on building a practical CRM solution for organizing and managing client leads efficiently.
